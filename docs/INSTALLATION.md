# Desktop installation

Installers are generated by the next desktop release build. Older releases may
only contain portable archives. Check the release's successful platform jobs and
compare the downloaded file's SHA-256 hash with its accompanying checksum.

## Windows

Run `Media-Manager-VERSION-windows-x86_64-setup.exe`. It installs for the current
user into `%LOCALAPPDATA%\Programs\Media Manager`, adds a Start menu shortcut,
and offers an optional desktop shortcut. Administrator access is not required.
If Microsoft WebView2 is missing, setup runs Microsoft's verified Evergreen
bootstrapper; that step requires an internet connection. Installed WebView2 is
shared with other applications and is kept when Media Manager is uninstalled.

Quit Media Manager before upgrading, then run the newer installer. Remove it
through Windows Settings → Apps → Installed apps, or the Start menu uninstaller.
Saved workspace settings and media files are retained. The backend executable
is included in the install folder; no background server or service is enabled.

Preview installers are unsigned unless publisher signing is configured. A
self-signed certificate does not provide public publisher trust.

## macOS

Choose the `aarch64.pkg` for Apple Silicon or `x86_64.pkg` for Intel. Open it and
follow Installer to place **Media Manager.app** in `/Applications`. The app
contains the server executable in `Contents/MacOS/media-manager-server` and
license notices in `Contents/Resources`. No daemon or login item is installed.

Quit the app before installing an update. To remove it, move Media Manager.app
from Applications to Trash. Workspace settings and your media are retained.
Requires macOS 13 or later. Preview packages are not Developer ID signed or
notarized, so Gatekeeper may block them; production distribution still requires
Apple signing and notarization. Do not disable system security protections.

## Linux

For Ubuntu 24.04 and compatible newer distributions, install the DEB using apt
so its declared dependencies are resolved:

```sh
sudo apt install ./Media-Manager-VERSION-linux-x86_64.deb
```

Launch **Media Manager** from the application menu or run `media-manager`.
The backend is available as `media-manager-server`, but is not started as a
service. Install a newer DEB with the same apt command to upgrade. Remove with
`sudo apt remove media-manager`; settings and library files are retained.

The DEB uses system GTK/WebKitGTK and a glibc floor determined by the build host;
it is not intended for older distributions. Use the existing
[Flatpak with managed runtime](LINUX_RUNTIME.md) on other supported Linux systems.
The TAR.GZ remains available for manual portable use with host dependencies.
